# Spotify Feature Analysis Dashboard

An interactive Power BI dashboard project focused on analyzing Spotify track features, artist popularity, genre distribution, and audio characteristics. This dashboard provides insights into music trends using visual analytics and explores relationships between features such as danceability, energy, speechiness, instrumentalness, and popularity.

## Features

* Genre-wise audio feature analysis
* Top artist popularity insights
* Danceability distribution of tracks
* Time signature analysis
* Interactive filters for genre and artist selection
* Treemap visualization for genre distribution
* Spotify-themed dashboard design

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Visualization
* Spotify Dataset

## Key Insights

* Identified highly popular artists and dominant genres
* Explored relationships between danceability, energy, and popularity
* Analyzed track characteristics across multiple genres
* Visualized audio feature distributions interactively
